
# Advancement of Software Engineering — Research Project

## Research Topic

**Evaluating Specification-Guided LLM Unit Test Generation Using Mutation Testing**

This project investigates whether providing software specifications to an LLM improves the quality of generated unit tests.

The study compares code-only and specification-guided prompting using GPT-6.1 Sol. Generated tests are evaluated through compilation, execution, and StrykerJS mutation testing on 12 functions from the Summit backend.
